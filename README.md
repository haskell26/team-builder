# 팀 빌더

오버워치 커뮤니티 운영자가 10명 매치를 빠르게 나누기 위한 정적 프론트엔드 앱입니다. 엑셀에서 복사한 `유저 이름 / 탱커 티어 / 딜러 티어 / 힐러 티어` 4열 표를 붙여넣거나, 이 브라우저에 저장해 둔 플레이어 10명을 불러오면 `1탱 2딜 2힐` 조건의 후보 6개를 비교하고 바로 스왑 편집할 수 있습니다.

## 이번 라운드 범위

- 헤더가 있는 입력과 없는 입력을 모두 지원합니다.
- 붙여넣는 즉시 10명 수, 중복 이름, 빈 셀, 지원하지 않는 티어 표기를 한국어로 검증합니다.
- 현재 매치 10명의 역할 선호도 `1순위 / 2순위 / 3순위` 를 UI 에서 직접 수정할 수 있습니다.
- 역할 선호도가 없으면 티어가 높은 역할 우선, 동점이면 `탱커 -> 딜러 -> 힐러` 순서로 기본값을 자동 적용합니다.
- 후보 6개는 압축 미리보기 카드로 렌더링되며, 각 슬롯은 티어 색상과 역할 선호도 배지를 함께 보여 줍니다.
- 후보 정렬은 총점 차이, 역할군별 차이 합, 탱커 차이, 언랭 분배 차이 순서를 그대로 유지합니다.
- 메인 UI 에서는 개인 점수, 팀 총점, 숫자 점수 차이를 표시하지 않습니다.
- 현재 10명의 티어와 역할 선호도를 로컬 저장소에 저장하거나 업데이트할 수 있습니다.
- 저장된 플레이어 목록에서 정확히 10명을 선택했을 때만 현재 매치로 불러올 수 있습니다.
- 선택한 후보 1개만 최종 편집 영역으로 불러오고, 슬롯 두 개를 차례대로 클릭하면 즉시 스왑됩니다.

## 사용 방법

1. 엑셀에서 10명 표를 복사해 붙여넣거나, 저장된 플레이어 목록에서 정확히 10명을 선택해 불러옵니다.
2. `현재 10명 확인 및 선호도` 영역에서 각 플레이어의 `1순위 / 2순위 / 3순위` 역할을 필요하면 수정합니다.
3. `팀 나누기`를 눌러 후보 6개를 비교합니다.
4. 후보 카드를 클릭해 `선택 후보 편집` 영역으로 불러옵니다.
5. 바꾸고 싶은 슬롯 두 개를 순서대로 클릭해 즉시 스왑합니다.

저장 기능은 현재 브라우저의 `localStorage` 를 사용하며, 별도 서버는 필요하지 않습니다.

## 개발 실행

### 요구 사항

- Node.js 22 이상
- Python 3 (`npm run preview` 사용 시)

### 설치

런타임 의존성이 없는 정적 앱이라 별도 `npm install` 없이 바로 실행할 수 있습니다.

### 테스트

```bash
npm test
```

현재 자동 검증 범위:

- 헤더 포함/미포함 TSV 파싱
- 역할 선호도 기본값, 중복 방지, 순위 배지 계산
- 저장 플레이어 로컬 저장소 래퍼와 upsert 동작
- exact-10 저장 플레이어 로드 흐름
- 후보 6개 생성, 정렬 우선순위, 중복 없는 슬롯 배치
- 후보 선택, 두 번 클릭 스왑, 스왑 뒤 티어/선호도 재계산
- 메인 엔트리 기준 저장/불러오기/선호도 편집 UI 흐름
- 티어 색상 클래스와 반응형 레이아웃 계약

### 빌드

```bash
npm run build
```

정적 배포 산출물은 `dist/` 에 생성됩니다.

### 브라우저 스모크 테스트

```bash
npm run test:browser -- --browser=/path/to/chromium
```

- Chromium 계열 브라우저가 있는 환경에서만 실행합니다.
- 이 스크립트는 빌드된 JS/CSS 를 headless Chromium 용 테스트 셸에서 열어 데스크톱 `1280px` 와 모바일 `360px` 뷰포트 기준의 기본 렌더링/스왑 흐름을 확인합니다.
- 이번 작업 환경에서는 Chromium 계열 바이너리를 찾지 못해 실행하지 않았습니다.
- 이번 스펙에서는 기존 브라우저/모바일 실기기 검증 공백을 blocker 로 간주하지 않습니다.

### 로컬 미리보기

```bash
npm run preview
```

기본 주소는 `http://localhost:4173` 입니다.

## GitHub Pages 배포

1. `npm run build` 를 실행합니다.
2. `dist/` 내용을 GitHub Pages 배포 브랜치나 `docs/` 폴더에 반영합니다.
3. 정적 파일만 사용하므로 별도 서버 로직은 필요하지 않습니다.

## 이번 검증 기록

- 실행: `npm test`
- 실행: `npm run build`
- 실행: `for name in chromium chromium-browser google-chrome google-chrome-stable microsoft-edge microsoft-edge-stable; do printf '%s: ' \"$name\"; command -v \"$name\" || true; done`
