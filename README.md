# 팀 빌더

오버워치 커뮤니티 운영자가 엑셀 표를 그대로 붙여넣어 10명을 두 팀으로 나눌 수 있는 프론트엔드 전용 도구입니다. 각 팀은 `1탱 2딜 2힐`로 고정되며, 배정된 역할의 티어 점수 합 차이가 가장 작은 조합을 계산합니다. 점수 차이가 같으면 언랭 배정 인원 차이가 더 적은 결과를 우선합니다.

## 사용 방법

1. 엑셀에서 `유저 이름 / 탱커 티어 / 딜러 티어 / 힐러 티어` 4개 열을 포함한 10명 표를 복사합니다.
2. 앱의 큰 입력창에 그대로 붙여넣습니다.
3. 입력 미리보기에서 정규화된 티어와 점수를 확인합니다.
4. `팀 나누기`를 눌러 추천 결과를 확인합니다.

## 티어 점수 기준

| 표기 | 점수 |
| --- | --- |
| U / 언랭 / Unranked | 0 |
| 브론즈 | 1 |
| 실버 | 2 |
| 골드 | 3 |
| 플래 / 플래티넘 | 4 |
| 다이아 | 5 |
| 마스터 | 6 |
| 그마 / 그랜드마스터 | 7 |

## 개발 실행

### 요구 사항

- Node.js 22 이상
- Python 3 (`npm run preview` 사용 시)

### 설치

이 프로젝트는 런타임 의존성이 없는 정적 앱입니다. 별도 `npm install` 없이 바로 실행할 수 있습니다.

### 테스트

```bash
npm test
```

`npm test`는 티어 정규화, TSV 파싱, 완전 탐색 옵티마이저, `src/main.js` 엔트리포인트를 통한 붙여넣기 → 검증 → 팀 계산 → 초기화 DOM 흐름, 그리고 모바일 반응형 레이아웃의 핵심 CSS 계약을 함께 검증합니다.

### 브라우저 스모크 테스트

```bash
npm run build
npm run test:browser -- --browser=/path/to/chromium
```

- Chromium 계열 브라우저(Chromium, Chrome, Edge)가 설치된 환경에서 실행합니다.
- 이 스크립트는 `dist/` 빌드 결과를 기준으로 데스크톱 `1280px` 와 모바일 `360px` viewport를 각각 headless 브라우저로 열고, 샘플 데이터를 자동으로 붙여넣어 결과 렌더링과 가로 오버플로 여부를 검사합니다.
- 로컬 포트를 열지 않고 `file://` 기반 임시 HTML 하네스로 실행하므로, 정적 배포물 그대로를 검증할 수 있습니다.
- 현재 이 샌드박스에는 브라우저 바이너리가 없어 실행이 실패할 수 있습니다. 그 경우 `--browser` 경로를 직접 지정해 주세요.

### 빌드

```bash
npm run build
```

빌드 결과물은 `dist/` 에 생성됩니다.

### 로컬 미리보기

```bash
npm run preview
```

기본 주소는 `http://localhost:4173` 입니다.

## GitHub Pages 배포

1. `npm run build`를 실행합니다.
2. 생성된 `dist/` 내용을 GitHub Pages 배포 브랜치나 `docs/` 폴더에 반영합니다.
3. `index.html` 기준 상대 경로만 사용하므로 별도 라우터 설정 없이 정적 호스팅할 수 있습니다.

## 구현 메모

- 파서는 탭 구분 텍스트를 기준으로 동작하며, BOM과 공백, 마지막 빈 줄을 정리합니다.
- 정확히 10명인지, 이름 중복이 없는지, 필수 셀이 비어 있지 않은지, 지원하는 티어 표기인지 한 번에 검증합니다.
- 최적화 로직은 10명을 모두 사용하는 완전 탐색이며, 결과가 항상 같도록 사전식 비교까지 포함합니다.
- 반응형 스타일은 모바일에서 메인 패널과 결과 카드가 한 열로 접히도록 구성했고, 표/샘플 영역은 자체 스크롤 컨테이너로 감싸 페이지 전체 가로 오버플로를 피하도록 설계했습니다.
- 이번 범위에는 역할 선호도, 저장 기능, 게임 확장은 포함하지 않았습니다.
