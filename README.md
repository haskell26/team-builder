# 팀 빌더

오버워치 커뮤니티 운영자가 엑셀에서 복사한 10명 표를 붙여넣으면 `1탱 2딜 2힐` 조건으로 밸런스가 좋은 팀 조합을 계산하는 정적 프론트엔드 앱입니다. 이번 라운드에서는 기존 단일 추천 흐름을 유지하면서, 상위 후보 6개를 역할군 밸런스까지 포함해 비교할 수 있도록 확장했습니다.

## 주요 기능

- 헤더가 있는 입력과 없는 입력을 모두 지원합니다.
  - 헤더를 쓸 경우 첫 비어 있지 않은 행이 정확히 `유저 이름 / 탱커 티어 / 딜러 티어 / 힐러 티어` 일 때만 헤더로 인식합니다.
- 붙여넣은 즉시 10명 수, 중복 이름, 빈 셀, 지원하지 않는 티어 표기를 한국어로 검증합니다.
- `팀 나누기`를 누르면 서로 다른 후보 조합 6개를 계산합니다.
- 각 후보에는 `팀 A / 팀 B 총점`, `점수 차이`, `역할군 차이 합`, `탱커 차이`, `언랭 분배 차이`가 표시됩니다.
- 후보 정렬 우선순위는 다음과 같습니다.
  1. 총점 차이 최소
  2. 역할군 점수 차이 합 최소
  3. 탱커 점수 차이 최소
  4. 언랭 분배 차이 최소
  5. 위 4개 지표가 모두 같을 때만 무작위 순서
- 첫 번째 후보가 기본 추천으로 자동 선택되고, 다른 후보를 클릭하면 상세 팀 구성만 즉시 바뀝니다.

## 티어 점수 기준

| 표기 | 점수 |
| --- | --- |
| U / 언랭 / Unranked | 0 |
| 브론즈 | 1 |
| 실버 | 2 |
| 골드 | 3 |
| 플래 / 플래티넘 | 4 |
| 다이아 | 5 |
| 마스터 | 6 |
| 그마 / 그랜드마스터 | 7 |

## 사용 방법

1. 엑셀에서 10명 표를 복사합니다.
2. 앱 입력창에 그대로 붙여넣습니다.
   - 헤더 행은 있어도 되고 없어도 됩니다.
3. 입력 확인 표에서 정규화된 티어를 확인합니다.
4. `팀 나누기`를 눌러 후보 6개를 확인합니다.
5. 후보를 클릭해 `팀 A / 팀 B` 상세 구성을 비교합니다.

## 개발 실행

### 요구 사항

- Node.js 22 이상
- Python 3 (`npm run preview` 사용 시)

### 설치

런타임 의존성이 없는 정적 앱이라 별도 `npm install` 없이 바로 실행할 수 있습니다.

### 테스트

```bash
npm test
```

다음 항목을 자동 검증합니다.

- 헤더 유무에 따른 TSV 파싱과 에러 행 번호
- 후보 6개 생성, 고유 조합 유지, 정렬 우선순위
- `src/main.js` 기준 후보 선택 UI 흐름
- 반응형 CSS 계약
- 브라우저 스모크 하네스 유틸리티

### 빌드

```bash
npm run build
```

정적 배포 산출물은 `dist/`에 생성됩니다.

### 브라우저 스모크 테스트

```bash
npm run test:browser -- --browser=/path/to/chromium
```

- Chromium 계열 브라우저가 있는 환경에서만 실행합니다.
- 이 스크립트는 빌드된 `dist/src/main.js`, `dist/src/styles.css`, 샘플 TSV를 임시 HTML 하네스에 로드해 데스크톱 `1280px` 와 모바일 `360px` 뷰포트를 점검합니다.
- 실제 `dist/index.html` 자체를 여는 검사는 아니므로, 브라우저 엔진 기준 기본 동작과 오버플로 리스크를 확인하는 보조 증거로 사용합니다.

### 로컬 미리보기

```bash
npm run preview
```

기본 주소는 `http://localhost:4173` 입니다.

## GitHub Pages 배포

1. `npm run build`를 실행합니다.
2. `dist/` 내용을 GitHub Pages 배포 브랜치나 `docs/` 폴더에 반영합니다.
3. 정적 파일만 사용하므로 별도 서버 로직은 필요하지 않습니다.

## 현재 범위

- 이번 라운드는 오버워치 10인 고정 매칭만 다룹니다.
- 역할 선호도, 저장 기능, 다른 게임 확장은 아직 포함하지 않았습니다.
- 실브라우저/실기기 검증은 자동 테스트와 별개로 후속 QA에서 추가 확인이 필요할 수 있습니다.
