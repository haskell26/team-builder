# 팀 빌더

오버워치 커뮤니티 운영자가 엑셀에서 복사한 10명 표를 붙여넣으면 `1탱 2딜 2힐` 조건으로 밸런스가 좋은 두 팀 후보 6개를 계산하는 정적 프론트엔드 앱입니다. 이번 라운드에서는 기존 입력과 후보 생성 흐름을 유지하면서, 숫자 점수 노출 없이 후보를 빠르게 비교하는 압축 미리보기 UI 와 최종 스왑 편집 영역을 추가했습니다.

## 주요 기능

- 헤더가 있는 입력과 없는 입력을 모두 지원합니다.
  - 첫 비어 있지 않은 행이 정확히 `유저 이름 / 탱커 티어 / 딜러 티어 / 힐러 티어` 일 때만 헤더로 인식합니다.
- 붙여넣는 즉시 10명 수, 중복 이름, 빈 셀, 지원하지 않는 티어 표기를 한국어로 검증합니다.
- `팀 나누기`를 누르면 서로 다른 후보 조합 6개를 계산합니다.
- 후보 카드는 `팀 A / 팀 B` 의 `1탱 2딜 2힐` 배치를 압축 미리보기 형태로 보여 줍니다.
- 티어는 지정된 색상 규칙으로 표시합니다.
  - 언랭 `white`
  - 브론즈 `bronze`
  - 실버 `silver`
  - 골드 `gold`
  - 플래티넘 `mint`
  - 다이아 `blue`
  - 마스터 `green`
  - 그랜드마스터 `violet`
- 결과 메인 UI 에서는 개인 점수, 팀 총점, 숫자 점수 차이를 표시하지 않습니다.
- 첫 후보가 기본 선택되며, 후보 카드를 누르면 최종 편집 영역이 해당 후보로 새로 로드됩니다.
- 최종 편집 영역에서는 슬롯 두 개를 차례대로 클릭해 바로 스왑할 수 있습니다.
  - 같은 역할끼리, 다른 역할끼리, 다른 팀끼리 모두 교체할 수 있습니다.
  - 교체 뒤 티어 표시는 도착한 슬롯 역할 기준으로 즉시 다시 계산됩니다.
  - 내부 팀 요약 데이터도 함께 다시 계산되어 이후 편집 상태와 표시가 어긋나지 않습니다.

## 후보 정렬 규칙

후보는 내부적으로 다음 우선순위로 정렬됩니다.

1. 총점 차이 최소
2. 역할군별 점수 차이 합 최소
3. 탱커 점수 차이 최소
4. 언랭 분배 차이 최소
5. 위 조건이 모두 같을 때만 무작위 순서

점수는 내부 계산에만 사용하며, 메인 화면에서는 숨깁니다.

## 사용 방법

1. 엑셀에서 `유저 이름 / 탱커 티어 / 딜러 티어 / 힐러 티어` 4열의 10명 표를 복사합니다.
2. 앱 입력창에 그대로 붙여넣습니다.
3. 입력 확인 표에서 이름과 티어 색상을 확인합니다.
4. `팀 나누기`를 눌러 후보 6개를 비교합니다.
5. 원하는 후보 카드를 클릭해 아래 최종 편집 영역으로 불러옵니다.
6. 바꾸고 싶은 슬롯 두 개를 순서대로 클릭해 즉시 스왑합니다.

## 개발 실행

### 요구 사항

- Node.js 22 이상
- Python 3 (`npm run preview` 사용 시)

### 설치

런타임 의존성이 없는 정적 앱이라 별도 `npm install` 없이 바로 실행할 수 있습니다.

### 테스트

```bash
npm test
```

자동 검증 범위:

- 헤더 포함/미포함 TSV 파싱
- 중복 이름, 빈 셀, 잘못된 티어 검증
- 후보 6개 생성과 정렬 우선순위
- stable slot id 기반 편집 모델
- 같은 역할/다른 역할 스왑 동작
- `src/main.js` 기준 후보 선택과 스왑 UI 흐름
- 티어 색상 클래스와 반응형 레이아웃 계약
- 브라우저 스모크 스크립트의 핵심 검증 로직

### 빌드

```bash
npm run build
```

정적 배포 산출물은 `dist/` 에 생성됩니다.

### 브라우저 스모크 테스트

```bash
npm run test:browser -- --browser=/path/to/chromium
```

- Chromium 계열 브라우저가 있는 환경에서만 실행합니다.
- 이 스크립트는 빌드된 JS/CSS 를 headless Chromium 용 임시 셸에서 열어 데스크톱 `1280px` 와 모바일 `360px` 뷰포트에서 아래 항목을 확인합니다.
  - 후보 카드 6개 렌더링
  - 최종 편집 영역 `2팀 x 5슬롯`
  - 첫 클릭 선택 상태
  - 두 번째 클릭 스왑 반영
  - 점수 라벨 비노출
  - 가로 오버플로 여부
- 현재 작업한 샌드박스에서는 Chromium 계열 바이너리를 찾지 못해 이 스모크 테스트는 실행하지 않았습니다.

### 로컬 미리보기

```bash
npm run preview
```

기본 주소는 `http://localhost:4173` 입니다.

## GitHub Pages 배포

1. `npm run build` 를 실행합니다.
2. `dist/` 내용을 GitHub Pages 배포 브랜치나 `docs/` 폴더에 반영합니다.
3. 정적 파일만 사용하므로 별도 서버 로직은 필요하지 않습니다.

## 현재 범위와 제한

- 이번 라운드는 오버워치 10인 고정 매칭만 다룹니다.
- 역할 선호도, 저장 기능, 다른 게임 확장은 아직 포함하지 않았습니다.
- `npm test` 와 `npm run build` 는 통과했습니다.
- 실브라우저/실기기 검증은 브라우저 바이너리가 있는 환경에서 후속 확인이 필요합니다. 이번 스펙에서는 이 항목을 blocker 로 간주하지 않습니다.
